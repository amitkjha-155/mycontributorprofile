# TechFest 2026

A simple, multi-page static website built with pure HTML to showcase **TechFest 2026**, a two-day student tech festival.

## Overview

This project serves as an informational and registration portal for TechFest 2026 (scheduled for **12 and 13 December**). It demonstrates foundational HTML structure, navigation, semantic elements, and multi-page linking.

## Features

* **Multi-Page Navigation:** Clean navigation bar linking the **Home**, **Events**, and **Register** pages.
* **Event Highlights:** Clear overview of the festival dates, featured banner image with caption, and key reasons to participate.
* **Event Schedule (Events Page):** Structured HTML table displaying day-wise event timings (e.g., Coding Contest, Web Design) using `rowspan` and `colspan`.
* **Registration Portal (Register Page):** Interactive HTML form allowing students to sign up for the event.

## Project Structure

```text
TechFest-2026/
├── index.html          # Home page (Welcome, event dates, banner, and highlights)
├── events.html         # Event schedule page with structured timing tables
├── register.html       # Student registration form page
├── images/             # Local assets and event banners
└── README.md           # Project documentation
```

## Getting Started

1. **Clone or download** this repository to your local machine.
2. **Open the project folder** and double-click `index.html` to view it in any web browser, or serve it using a local development server (such as VS Code Live Server or Python's `http.server` on `localhost`).

## Technologies Used

* **HTML5:** Semantic tags (`<header>`, `<nav>`, `<figure>`, `<figcaption>`, `<mark>`, `<table>`, `<form>`).
